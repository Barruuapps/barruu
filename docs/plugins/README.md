# Plugins (Future)

*Coming in a future release.*

The plugin system will allow developers to extend Barruu with custom functionality.

## Vision

Barruu's plugin system will enable:

- Custom block types (e.g., timeline, kanban, 3D viewer)
- Theme extensions
- Export format plugins
- AI integration plugins
- Authentication provider plugins

## Plugin API (Planned)

The plugin API will be built in Dart, enabling Flutter-native integration with full access to the block editor, storage layer, and theming system.

*Detailed plugin development guides will be created as the system is implemented.*
