# Changelog

All notable changes to Barruu will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project setup with Flutter
- Block-based editor with core block types (text, header, list, code, quote, columns)
- Graph visualization blocks (chart, diagram)
- Audio reader block
- Chat reader block
- Stepper block for tutorials
- Fill-in-the-blank interactive block
- Math rendering with LaTeX support
- Workspace management for organizing documents
- User profile functionality
- Home screen with content feed
- Onboarding flow
- Cross-platform support for Linux, macOS, Windows, Android, iOS
- Offline-first architecture using SQLite (Sqflite)
- Riverpod state management
- GoRouter navigation
- Freezed code generation for immutable models

## [0.1.0] - 2024-01-15

### Added

- Initial public release of Barruu
- Block-based editor with slash commands
- Rich text formatting
- Desktop (Linux, macOS, Windows) support
- Mobile (Android, iOS) support
- Offline-first data storage
- Basic export capabilities
